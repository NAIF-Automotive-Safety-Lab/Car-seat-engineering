# P0 COST-MINIMUM ARCHITECTURE

## Compared configurations

| Configuration | Can prove bilateral load path? | Separate rotation path? | State transition? | Rebound? | Verdict |
|---|---:|---:|---:|---:|---|
| Single-side subsystem | No | Partial | Possible | Partial | Reject |
| Half-width rig | No | Partial | Possible | Partial | Reject for core hypothesis |
| Dual-side carriage rig | Yes | Yes | Yes | Yes | **Minimum core demonstrator** |
| Full seat without instrumentation | Yes | Yes | Yes | Yes | More hardware than necessary for first mechanical proof |
| Full instrumented seat | Yes | Yes | Yes | Yes | Needed later for integrated evidence, not minimum |

## Decision

The **dual-side carriage rig** is the minimum configuration that preserves the core architectural hypothesis.

A single-side rig is scientifically insufficient because the V7 architecture explicitly treats bilateral load paths and separate left/right reactions as part of the inventive/mechanical relationship. fileciteturn29file5L1-L8

The first article should therefore be a modular, dual-rail, non-occupant mechanism rather than a cosmetically complete production-style seat.
