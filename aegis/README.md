# V7-AEGIS Engineering Orchestration Kernel (AEOK)

AEOK is a **fail-closed orchestration foundation**, not a claim of certified physical safety or a replacement for accredited testing. It maintains a content-addressed evidence graph, a hash-chained transition ledger, explicit engineering phases, typed worker contracts, and a release policy that returns `BLOCK` unless requirements, native CAD, BOM, material certificates, CAE results, raw test data/reports, regulatory evidence, manufacturing plan, and independent audit are present.

Configured worker adapters must produce hash-bound artifacts. The supplied default workers deliberately block because no trusted live CAD, solver, test-lab, LLM-provider, supplier, or regulatory adapter is configured in this repository.
