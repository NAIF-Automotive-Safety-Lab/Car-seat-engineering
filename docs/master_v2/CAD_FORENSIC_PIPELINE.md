# CAD Forensic Pipeline

The CAD firewall requires accessible bytes, file size, SHA-256, immutable copy, identity re-verification, and replay. When a released V7 STEP payload arrives, STEPcode or step-p21 and OCP/OpenCascade must be run independently and compared. Disagreements are recorded, not hidden. B-Rep results must reference the source SHA-256.

Current R4.1 OCP evidence is verified for R4.1 only. V7 forensic status remains BLOCKED until the released V7 native payload is supplied.
