# EVA — Engineering Virtual & Evidence Acquisition Engine

EVA operates above and alongside EERE, CAD/B-Rep, PMI, the Engineering Evidence Graph, physics, dynamics, FEA interfaces, instrumentation, testing, and configuration management. It discovers authorized sources, extracts context-bound values, derives defensible quantities, represents uncertainty, runs controlled virtual experiments, ranks sensitivities, prioritizes minimum-information tests, and records calibration readiness.

EVA is not a validation shortcut. `CALCULATED`, `SIMULATED`, `ASSUMED`, `TARGET`, and `CANDIDATE` records cannot be promoted to `MEASURED_PHYSICALLY` or `VALIDATED` without the corresponding evidence. Synthetic experiments prove software behavior only and never enter project validation evidence.

The current runtime is **PARTIAL**: source discovery, provenance-bound parameter records, derivation, interval bounds, synthetic experiments, sensitivity, prioritization, calibration records, and A–O EVA fields execute. V7-specific validation remains blocked by missing V7 source and physical evidence.
