# P0 Exploratory Fabrication Definition

## Classification
**PROTOTYPE / TEST ARTICLE — NOT PRODUCTION HARDWARE**

P0 is designed to be manufacturable and repeatedly modifiable, but this document is not a production release. The original V7 document itself warns that generated CAD figures are not verified CAD and that the concept remains a research prototype.

## Exact first hardware to fabricate
Build **P0-E / V0 integrated exploratory mechanism** as a non-occupant bench article with: base fixture 100, bilateral rails 110L/110R, carriage 120, modular absorber interface 130, independent rotation-control links 150L/150R, seatback frame 160, replaceable lock 170, replaceable rebound control 180, joint/fastener set J, and sensor panel 210.

## What may be exploratory
- bolt-on adapters;
- sacrificial contact inserts;
- interchangeable absorber cartridges;
- replaceable lock internals;
- replaceable rebound modules;
- instrument brackets;
- local fixture dimensions that do not define R4.1 functional geometry.

## What must not be improvised
- critical rail axes without a documented datum basis;
- load-introduction interfaces that change the intended load path without a deviation record;
- occupant restraint anchorage used for a human occupant;
- safety stop retention;
- load ratings of structural/fixture members.

## Source-reference nominal geometry
The concept package contains reference values including approximately 180 mm rearward stroke, 210 mm total travel, 520/560 mm rail/package dimensions and a -10 to +25 degree seatback motion envelope. These are **DESIGN REFERENCES**, not manufacturing truth and not measured test results. Exact fabrication dimensions requiring R4.1 replication remain dependent on native CAD extraction.

## Fabrication inspection
Before dynamic testing, verify: datum integrity, rail alignment, carriage free motion, positive stop engagement, absorber axis alignment, lock engagement, rebound directionality, fastener traceability, sensor mounting and cable clearance.
