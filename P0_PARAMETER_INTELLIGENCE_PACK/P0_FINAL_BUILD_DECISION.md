# P0 Final Build Decision

**MINIMUM_PHYSICAL_ARTICLE:** dual-side carriage development rig preserving bilateral load paths, controlled longitudinal translation, energy-management path, separate seatback rotation control, state transition, rebound control, and development-only restraint interface.

**WHY_THIS_IS_MINIMUM:** a half-width or single-side rig removes the bilateral relationship; a module-only rig cannot demonstrate integrated translation/rotation/state/rebound behavior.

**WHAT_IT_CAN_PROVE:** limited developmental geometry, motion, state, rebound, and instrumented component behavior after evidence acquisition.

**WHAT_IT_CANNOT_PROVE:** safety, crash performance, vehicle compatibility, production equivalence, certification, homologation, or FE validity.

**MUST_BE_KNOWN_BEFORE_BUILD:** configuration identity, physical part list, actual materials/processes, interfaces/datums, deviations, and selected mechanism options.

**CAN_BE_MEASURED_AFTER_BUILD:** geometry, alignment, travel, motion, state transitions, reverse motion, forces/displacements where instrumented.

**MUST_WAIT_FOR_SPECIALIZED_TEST:** absorber law, friction/contact laws, joint/bolt properties, pulse/velocity, FE inputs, occupant/vehicle safety evidence.

`R4.1 = FROZEN`; `R4.2 = NOT_AUTHORIZED`; `PHYSICAL_DATA = 0`; `FE = NOT_AUTHORIZED`.
