## Minimum P0 build set

The smallest defensible article requires the frozen R4.1 traceability basis, a verified physical part/interface list, actual material/process/deviation records, controlled datums, bilateral load paths, carriage translation, an energy-management path, separate seatback rotation control, state transition, rebound control, and a development-only restraint interface.

This is not a manufacturing release and does not prove functional equivalence or safety.
