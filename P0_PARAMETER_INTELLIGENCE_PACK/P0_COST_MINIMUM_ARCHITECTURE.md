# P0 Cost-Minimum Architecture

| Configuration | Decision | Reason |
|---|---|---|
| Full seat | Deferred | More complete packaging but not minimum for mechanism demonstration |
| Half-width rig | Rejected for core proof | Removes bilateral load-path relationship |
| Single-side subsystem | Rejected for core proof | Cannot demonstrate bilateral reactions/torsional control |
| Dual-side carriage rig | **Minimum recommended** | Preserves bilateral paths, translation, absorber, independent rotation, state and rebound |
| Module-level absorber rig | Useful secondary rig | Characterizes 130 only; does not prove integrated architecture |

This is a development recommendation, not a safety-equivalent vehicle article.
