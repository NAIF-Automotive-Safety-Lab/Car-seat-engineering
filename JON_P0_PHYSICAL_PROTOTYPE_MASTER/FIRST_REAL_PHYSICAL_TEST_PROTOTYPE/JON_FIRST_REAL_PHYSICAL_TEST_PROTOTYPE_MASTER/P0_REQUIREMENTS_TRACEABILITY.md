# P0 Requirements Traceability

| Requirement | Physical evidence | Test(s) | Evidence class | Gate |
|---|---|---|---|---|
| Guided translation occurs | x(t), S1/S2 reactions, video | P0-T02, T03, T14 | PHYSICAL | Gate 2 |
| Translation path is controlled | x(t), force, stop/state | P0-T14, T18 | PHYSICAL | Gate 2 |
| Rotation-control is independent | theta(t), link loads | P0-T15 | PHYSICAL | Gate 2 |
| Absorber engages | absorber force/stroke | P0-T08, T09 | PHYSICAL | Gate 2 |
| Energy is dissipated through intended path | integral F dx with reaction audit | P0-T08, T18 | PHYSICAL | Gate 2 |
| Lock transitions reliably | state channel + video | P0-T13 | PHYSICAL | Gate 2 |
| Rebound is controlled | reverse x/v/force/state | P0-T16, T18 | PHYSICAL | Gate 2 |
| No binding/interference | inspection + kinematics/video | P0-T01, T02, T14 | PHYSICAL | Gate 1/2 |
| Reactions measurable | S1/S2/absorber/link force | P0-T03, T08, T15 | PHYSICAL | Gate 2 |
| Repeatable reset | post-test inspection + rerun | P0-T19 | PHYSICAL | Gate 2 |

P0 evidence does **not** constitute occupant safety validation.
